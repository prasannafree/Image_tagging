# description of this project 

this system takes an image and automatically generates multiple tags describing what is present in the image . 
it is a multi-label iamge tagging 


the robot transport the materials from one place to another place , there is no need to detect the object's position unless there is some dangerous object since the object detection with position is compute heavy . 




# three semantic categories 

- environment : warehouse , aisle , storage_area , loading_area , packing_area 
- object : shelf , pallet , box , container , person , forklift 
- navigation : clear_path , obstructed_path , crowded
